# Doutch Records — Site officiel

Site vitrine du label indépendant **Doutch Records**.

## Aperçu
- Identité visuelle noire, rouge et blanche
- Site responsive (mobile, tablette et ordinateur)
- Présentation du label, des services, des productions et des contacts
- Navigation mobile et liens de contact par e-mail

## Mise en ligne avec GitHub Pages
1. Ouvrir les paramètres du dépôt (**Settings**).
2. Aller dans **Pages**.
3. Dans **Build and deployment**, choisir **Deploy from a branch**.
4. Sélectionner la branche **main** et le dossier **/(root)**, puis enregistrer.
5. GitHub affichera l'adresse publique du site après le déploiement.
